# Game Developer | Playable Game Prototypes

I turn game ideas into playable prototypes and help developers bring gameplay systems to life.

## What I Do

- **Playable Prototypes** — turning concepts and game design documents into playable builds
- **Unity Development** — gameplay mechanics, systems, and prototyping
- **HTML5 & Phaser Games** — browser-based games and interactive experiences
- **Gameplay Systems** — progression, combat mechanics, abilities, and game logic
- **Bug Fixing & Iteration** — testing, debugging, and improving existing prototypes
- **AI-Assisted Development** — faster implementation with human review, testing, and version control

## Featured Project

### Hell's Frontier — Tactical Strategy Game

A released HTML5 strategy game showcasing gameplay systems, tactical combat, progression, and browser-based delivery.

**Play the game:** https://svinopas707.itch.io/hells-frontier

## My Approach

I focus on getting the core gameplay loop playable early, validating mechanics through iteration, and delivering work in clear, manageable milestones.

My goal is to help turn ideas into working builds that can be tested, evaluated, and developed further.

## Available for Freelance Projects
